# generative-ui-builder
# AI-Powered HTML Interface

##  Overview
This project is a web interface that allows users to generate and edit HTML components using an AI model (LLaMA via Groq API).

## Features
- AI-based HTML generation
- Inline editing (double click)
- Undo / Redo using stack system
- Component history
- Import / Export HTML
- DOM Tree Viewer

##  Tech Stack
- JavaScript
- HTML / CSS
- Groq API (LLaMA)
